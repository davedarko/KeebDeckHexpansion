# Keebdexpansion

A keyboard hexpansion for the [Tildagon badge](https://tildagon.badge.emfcamp.org/) using the [solder.party KeebDeck Keyboard](https://www.solder.party/docs/keebdeck/keyboard/). Software for the hexpansion is [provided by @sodoku](https://github.com/sodoku/tildagon-keebdexpansion).

![Keepdexpansion V1 connected to the Tildagon](/images/tildagon_keebdeck_v1.jpeg)

## Features

- Full layout keyboard
- RGB-Backlit keys
- Type in text inputs
